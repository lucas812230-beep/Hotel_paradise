🏨 Hotel Paradise

Sistema web desenvolvido para simular a apresentação e o processo de reserva de um hotel.

📌 Sobre o projeto

O Hotel Paradise é um projeto desenvolvido com o objetivo de praticar desenvolvimento web e criar uma experiência simples e intuitiva para usuários que desejam conhecer o hotel e realizar uma reserva.

🚀 Funcionalidades

* Página inicial com apresentação do hotel
* Exibição de informações sobre os quartos
* Sistema de reserva
* Interface responsiva
* Navegação entre as páginas
* Layout desenvolvido pensando na experiência do usuário

🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

🎯 Objetivo

Projeto desenvolvido como parte dos meus estudos em Análise e Desenvolvimento de Sistemas, com foco no desenvolvimento de interfaces web, organização de código e experiência do usuário.
